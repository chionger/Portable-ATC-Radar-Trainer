benchmark evidence. Neither establishes that a future machine can restore an
inference runtime without external retrieval. FP-001D adds separate versioned

outside Git. Containers are an optional convenience and cannot satisfy durable
artifact requirements on their own. Git safety checks cover runtime packages,
binaries, artifact directories and Model Zoo archives. No model catalogue entries,

The [operating guide](../../model-zoo/runtime-preservation/README.md) specifies
bootstrap, clean restoration, dependency closure checks, OS network isolation,
local model loading, small inference and evidence review. The reference recipe is
CPU/float32 only, without benchmark or production integration work.
